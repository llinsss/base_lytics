# 📊 BaseLytics Analytics Dashboard Guide

Comprehensive data visualization and insights for your BaseLytics ecosystem.

## 🚀 Quick Access

### Navigation
- **Analytics Dashboard**: `http://localhost:3000/analytics`
- **Main Dashboard**: `http://localhost:3000/`
- **Activity Feed**: `http://localhost:3000/activity`
- **Status Monitor**: `http://localhost:3000/status`

## 📈 Dashboard Components

### 1. **Key Metrics Cards**
- **Token Supply** - Current supply with utilization percentage
- **NFTs Minted** - Total minted with revenue in ETH
- **Total Staked** - Staking TVL with current APY
- **Active Users** - Number of staking participants

### 2. **Interactive Charts**

#### Token Supply Growth Chart
- **Line chart** showing token supply over time
- **30-day trend** with growth patterns
- **Hover tooltips** with exact values
- **Responsive design** for all screen sizes

#### NFT Revenue Chart
- **Bar chart** displaying daily NFT minting
- **Revenue calculation** based on mint price
- **Total revenue** summary below chart
- **Mint price** display for reference

#### Staking Analytics Chart
- **Area chart** showing Total Value Locked (TVL)
- **Staking growth** trends over time
- **Current APY** and TVL metrics
- **Gradient fill** for visual appeal

### 3. **Time Range Filters**
- **7 days** - Recent activity focus
- **30 days** - Monthly trends (default)
- **90 days** - Quarterly analysis

### 4. **Export Functionality**
- **CSV export** of all time series data
- **Filename** includes timestamp
- **Data includes** token supply, NFT minting, staking TVL

## 📞 Troubleshooting

### Common Issues

**Charts not loading**
- Check contract deployment status
- Verify network connection
- Refresh analytics data

**Incorrect data**
- Ensure contracts are properly configured
- Check time range selection
- Verify blockchain sync status

**Export not working**
- Check browser download permissions
- Ensure data is loaded
- Try different time ranges

### Performance Tips
- **Use appropriate** time ranges for analysis
- **Export data** for complex analysis
- **Refresh regularly** for latest data
- **Check network** status if slow
